Install on your phone

Android · Download APK
  1. Download APK tap karke file download karo.
  2. Downloaded SignalPay-demo APK kholo aur Android ke install prompts review karke follow karo.
  3. SignalPay Demo open karo. QR scan ke liye Start camera tap karo aur camera permission do.

Android 8.0 ya newer required. Browser aur Android settings ke mutabiq install confirmation aa sakti hai. Banking ya SMS permissions nahi mangi jati.

iPhone · Safari
  1. Is link ko Safari mein kholo.
  2. Share kholo, phir Add to Home Screen select karo.
  3. Open as Web App option aaye to on rakho, phir Add tap karo.

WhatsApp ya kisi aur app ke andar link khula hai? Menu se Chrome / Safari mein open karo. iPhone par APK install nahi hoti; Safari ke Add to Home Screen steps use karo.
